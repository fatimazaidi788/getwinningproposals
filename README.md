# Get Winning Proposals (getwinningproposals.com)

Official homepage for **Get Winning Proposals** — the AI-powered proposal and contract closing platform designed for freelancers, agencies, and revenue teams.

## 🚀 Features

- **Responsive Landing Page**: Built with modern CSS variables, glassmorphism visual design, and dark theme.
- **Interactive Proposal Preview**: Simulates AI proposal generator and real-time client analytics.
- **Dynamic Pricing Calculator**: Toggle between monthly and discounted annual billing.
- **SEO & Social Metadata**: Integrated Open Graph and meta tags for `getwinningproposals.com`.

## 🛠️ Stack

- **HTML5** with Semantic tags & Open Graph metadata
- **Vanilla CSS** with modern Flexbox/Grid, glowing gradients & micro-interactions
- **Vanilla JavaScript** for UI interactive states
